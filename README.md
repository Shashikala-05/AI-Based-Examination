\# AI-Based Intelligent Examination Platform



\## Project Overview

The AI-Based Intelligent Examination Platform uses Artificial Intelligence

to generate examination questions and evaluate student answers.



\## Technologies Used

\- Python

\- LangChain

\- OpenAI

\- Google Gemini

\- Streamlit

\- SQLite



\## Milestone 1



\### Task 1: AI Model Integration

Integrates OpenAI and Google Gemini using LangChain to generate answers

to the same user prompt.



\### Task 2: MCQ Generation

Generates multiple-choice questions based on the selected topic,

difficulty level, and number of questions.



\### Task 3: Examination and Evaluation

Allows students to select answers, submit the examination,

and view their results.



\### Task 4: AI Examination

Provides AI-based examination functionality.



\### Task 5: Written Answer Evaluation

Supports MCQ evaluation, written answers, image-based answer extraction,

and AI-powered evaluation.



\## Milestone 2

Implements student, teacher, and administrator authentication

using Streamlit and an SQLite database.



\## How to Run



1\. Activate the Python virtual environment.

2\. Install the required packages.

3\. Configure your API keys in the `.env` file.

4\. Run the required Python script or Streamlit application.



\## Security

Keep API keys and other secrets private. Never upload your `.env`

file or passwords to GitHub.
